# 📖 Overview

GitOps is a modern operational framework that uses Git as the single source of truth for declarative infrastructure and application deployments.

In this module, I explored the fundamentals of GitOps using **ArgoCD**, learned how continuous deployment works in Kubernetes, and organized the project into daily milestones for better learning and documentation.

---

# 🎯 Learning Objectives

- Understand GitOps concepts
- Learn Continuous Deployment with ArgoCD
- Install and configure ArgoCD
- Manage Kubernetes applications declaratively
- Explore synchronization and self-healing
- Organize GitOps projects professionally
- Maintain documentation for each learning day
